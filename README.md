# Password-Generator

- A simple Password Generator built using HTML, CSS, and JavaScript. This web app generates strong and secure passwords with customizable options.

## Features

- Generate random passwords with a mix of uppercase, lowercase, numbers, and special characters.

- Set password length according to your preference.

- Copy the generated password to the clipboard with a single click.

- Responsive design for seamless use on mobile and desktop devices.

## Technologies Used

- HTML: Structure of the webpage

- CSS: Styling and layout

- JavaScript: Functionality and password generation logic

## How to Use

- Open the Password Generator in your browser.

- Select the desired password length and character types.

- Click the "Generate Password" button.

- Copy the password using the "Copy" button.
